# D2R Reimagined — 공속 제한 해제 계산기 (v1.6 소환수 확장 실험판)

**GitHub Pages에서 동작하는 독립형 정적 웹사이트.** 별도 계정 로그인, 서버, 데이터베이스, 유료 도메인, npm 빌드 과정이 필요하지 않습니다.

## 시작하기

1. 이 ZIP을 압축 해제합니다.
2. GitHub에서 **Public** 저장소를 하나 만듭니다. 예: `d2r-uncapped-ias`.
3. 압축 해제한 파일 `index.html`, `style.css`, `data.js`, `core.js`, `main.js`, `summons.js`, `.nojekyll` 등을 **저장소 최상위(root)**에 업로드합니다. ZIP 자체를 업로드하는 것이 아닙니다.
4. GitHub 저장소 **Settings → Pages → Build and deployment → Deploy from a branch**를 선택합니다.
5. `main` 브랜치와 `/ (root)` 폴더를 지정하고 저장하면 `https://사용자이름.github.io/d2r-uncapped-ias/` 같은 주소가 발급됩니다. GitHub 설정이나 운영 정책에 따라 주소가 다를 수 있습니다.
6. 모바일에서도 같은 주소로 접근할 수 있습니다.

> 인터넷에 게시하기 전 자신의 PC에서 검사하려면 이 폴더에서 `python -m http.server 8000` 실행 → 브라우저에서 `http://localhost:8000`에 접속합니다. ES 모듈을 사용하므로 `index.html`을 `file://`로 직접 열면 일부 브라우저에서 동작하지 않을 수 있습니다.

## 중요 — 계산 신뢰도

**이 버전은 공개하기 전에 테스트할 수 있는 기능 구현판입니다. 모든 특수 스킬에 대해 정확한 게임 판정 프레임을 보장하지 않습니다.**

| 결과 유형 | 구현 방식 | 주의 사항 |
|---|---|---|
| 기본 공격·투척·일반 모션 | 직업별 기본 공격 애니메이션 FPD와 IAS 공식 | 모딩으로 애니메이션이 바뀌면 실제값과 차이 가능 |
| 광분 | 기존 대화에 보존된 12.5~1F **이론** 브레이크포인트, 양손의 IAS 따로 반영 | 실제 쌍수 시퀀스 첫/둘째 공격의 타격 간격과 단순 1:1 대응하지 않을 수 있음 |
| 훨윈드 | 한손/쌍수 선택, 양손별 WSM 및 IAS 계산, 쌍수 시 추정 프레임 평균·올림 | **쌍수 출력은 공식 2.4.3 평균·올림 규칙을 따르지만**, 손별 훨윈드 프레임 추정식과 상한 해제 패치의 실제 히트체크는 미검증 |
| 열의·속사·난격·분노·암살자 복합 스킬 | 롤백/시퀀스 계수 근사 | 실제 프레임표로 사용하기 전에 검증 필요 |
| 악마술사 가르기·거울 칼날 등 | **계산 미지원**으로 명시 | 해당 스킬의 검증된 하드코딩 시퀀스 정보 필요 |
| 변신(늑대/곰) | 근사치 | 별도의 애니메이션 전용 데이터 필요 |
| 1~2F 구간 | 상한 해제 후 이론 계산 | 엔진 최소 타격 간격/내부 판정 루틴 제한은 별도 |
| **소환수 공격 (v1.6)** | 알려진 소환수 공격 애니메이션의 공개 브레이크포인트를 인용하고 이후 구간은 이론 외삽 | **실제 소환수 AI 공격 대기, 명중 횟수, 특수 스킬 캐스팅 판정과 다름**; 리이매진드 모드에서 동일한 애니메이션인지 미확인 |

**원본 Reimagined 웹사이트를 코드 단위로 복제한 제품이 아닙니다.** UI와 계산기는 별도로 작성했으며, 참고 사이트의 모든 특수 공격을 정확히 재현했다고 주장하지 않습니다. 일부 지원 스킬을 순차적으로 정밀화해야 합니다.

### 기술적 전제

- 장비 IAS 점감 공식: `EIAS_item = floor(120 * IAS_total / (120 + IAS_total))`.
- 최종 EIAS: `EIAS_item + SIAS - WSM`.
- 일반 공격은 모션별 기본 프레임 데이터에 근거하여 계산합니다.
- 광분의 별도 프레임표는 사용자가 이전 대화에서 보존한 이론값을 사용합니다. 프레임당 실제 타격 여부는 검증 대상입니다.
- 듀얼 무기 WSM 평균 및 손별 무기 IAS 처리는 **표시와 모의 계산용 단순화 모델**로서 실제 광분의 시퀀스·명중 판정에 따른 차이를 포함하지 못합니다.
- 고급 `기본 모션 프레임 덮어쓰기` 항목은 Reimagined에서 모션을 수정한 경우에만 사용하세요.
- 워록 `Sigil Lethargy`는 Reimagined `skills.txt`에 명시된 attackrate -25를 반영했습니다. `Hex Purge`의 사용자 공격속도 보너스는 `passivecalc1=min(30,ln56)` (Param5=10, Param6=1)의 양수값을 적용합니다: 레벨 1 +10%, 레벨 20 +29%, 레벨 21부터 +30%. 실제 대상별 적용 조건은 게임 내 확인이 필요합니다.
- `Wolverine Aura`는 Reimagined의 `aurastatcalc3 = min(par9+blvl-1,30)`, `par9=6`을 근거로 계산하며 아이템 스킬레벨은 포함하지 않습니다.

## v1.3 변경사항 — 훨윈드 쌍수 지원

- 야만용사 **훨윈드**에서 쌍수 체크박스를 사용할 수 있습니다. 한손 사용도 계속 지원합니다.
- 쌍수 선택 시 두 무기의 WSM 및 무기 IAS를 별도로 계산해 **주무기/보조무기 예상 프레임**을 표시합니다.
- 쌍수 훨윈드에 한해 두 프레임을 평균한 뒤 올림하여 **예상 공용 타격 판정 간격**으로 표시합니다. 이는 [블리자드 2.4.3 패치 노트](https://news.blizzard.com/en-gb/article/23814050/diablo-ii-resurrected-patch-2-4-3-now-live)의 쌍수 평균·올림 규칙을 반영한 **근사 모델**입니다.
- 쌍수 훨윈드 선택 상태에서는 한손 무기 및 바바리안이 쌍수로 장착할 수 있는 양손 검만 목록에 보여줍니다. 두손창·미늘창·양손 도끼 등은 제외됩니다. 기존에 사용한 부적합한 무기를 착용한 상태에서 쌍수로 전환하면 목록의 첫 유효 무기로 대체됩니다.
- 프레임표는 선택한 손의 **개별 추정 프레임**이며, 쌍수 합산 판정 간격의 직접 브레이크포인트표가 **아닙니다**. 쌍수 훨윈드의 초당 실타수 역시 검증 전이므로 표시하지 않습니다.
- 현재 사용자 커스텀 패치에서 1~2F까지 히트체크가 실제로 진행되는지는 데이터만으로 확정할 수 없습니다.

GitHub Pages에 반영하려면 ZIP 안의 파일을 기존 `index.html`이 있는 **저장소 최상위 폴더**에 덮어쓰세요.


## v1.4 변경사항 — 바바리안 양손검 한손/양손 장착

- **바바리안 + 양손검 + 일반 공격·강격(Bash)·기절(Stun)·집중(Concentrate)·광폭화(Berserk)**에서만 `장착 방식` 선택 메뉴가 표시됩니다.
- **두 손으로 사용:** `2HS` 기본 모션 **18 FPD**. **한 손으로 사용(방패 장착 등):** `1HS` 기본 모션 **16 FPD**. `WSM` 및 장비 IAS는 유지되며 애니메이션만 교체됩니다.
- 바바리안이 양손검 두 자루를 사용해 쌍수 일반 공격/이중 타격을 수행한다면 자동으로 **1HS** 모션을 적용합니다. 광분은 기존 별도 이론 시퀀스 모델을 유지합니다.
- **훨윈드**는 별도 타격 간격 계산을 사용하므로 장착 방식 메뉴를 표시하지 않고 v1.3 계산식을 유지합니다.
- 기존 고급 옵션 `기본 공격 모션 프레임(FPD) 덮어쓰기`를 사용하면 입력한 사용자 지정 FPD가 우선합니다.
- 기존 공유 링크 및 브라우저 저장 설정에는 `swordGrip` 속성만 새로 추가됩니다. 기존 저장값에서는 **2HS(두 손)**가 기본값이며, 선택 상태는 저장·공유됩니다.
- 프레임표와 현재 프레임은 **선택된 장착 방식에 따라 동시에 변경**되도록 연결했습니다. 이론·근사 프레임 및 패치 실측 미검증 관련 주의사항은 v1.3과 동일합니다.

- 기존 무기 선택 ID를 유지해 저장된 링크와 브라우저 설정의 호환성을 최대한 유지했습니다. 수정된 기본 WSM과 같았던 **이전 자동 입력값만** 새 기본값으로 갱신합니다. 사용자가 수동 입력한 다른 WSM 값은 보존합니다.
- 신규 베이스의 상당수는 게임 내부 영문 표기로 등록했습니다. 사용자가 지정한 아타그한/리인포스드 메이스 등의 주요 명칭은 한글도 함께 제공됩니다.
- **주의:** 이 수정은 무기 베이스 데이터 교체입니다. 기존 계산 엔진의 특수 스킬 1~2F 이론값, 훨윈드/광분 시퀀스의 실측 미검증 문제를 해결하는 변경은 아닙니다.


## v1.6 변경 사항 — 소환수 공격속도 계산기

공격 스킬 목록에서 **`소환 · ...`**을 선택하면 소환수 전용 입력 모드가 열립니다. 기존 캐릭터의 무기 IAS, 방어구 IAS, 광분 및 폭발적인 속도는 기본적으로 **소환수에게 자동 상속되지 않습니다**.

### 지원 항목

| 직업 | 지원 소환수/스킬 | 계산 기준 |
|---|---|---|
| 아마존 | 발키리 | 공개 공격 모션 브레이크포인트 참조 |
| 강령술사 | 해골 전사, 해골 마법학자, 점토/피/강철/화염 골렘 | 공개 프레임 구간 참조 |
| 강령술사 | 부활 | 몬스터 공격 기준 FPA를 사용자가 입력할 때만 이론 계산 |
| 드루이드 | 영혼 늑대, 광포한 늑대, 회색곰(일반 공격/강타) | 공개 프레임 구간 참조 |
| 드루이드 | 큰까마귀, 덩굴 | 전용 AI/시퀀스가 미확인: 프레임 자동 계산 보류 |
| 암살자 | 그림자 전사, 그림자 달인(일반 공격/연타 참고) | 공개 프레임 구간 참조, 연타는 추정 |
| 악마술사 | 염소인간, 오염된 자, 파멸자, 악마 속박 | 스킬 레벨별 **소환수 공속 보너스만 자동 계산**, 공격 모션은 사용자가 직접 측정한 기준 FPA 필요 |

### 버프 계산

- **소환 스킬 레벨**: 원본 `skills.txt`에서 직접 `attackrate`를 증가시키는 소환 스킬만 자동으로 상승합니다. 강령술사의 해골·골렘이나 드루이드 늑대·곰은 소환 레벨만으로 **자동 공속 증가가 있다고 가정하지 않습니다**.
- **악마술사 전용**: Reimagined의 염소인간/오염된 자는 소환 스킬 레벨에 따라 `10 + (레벨-1)`, 최대 **+25% SIAS**. 악마 숙련은 `5 + (레벨-1)`, 최대 **+25%**, 포식은 `15 + (레벨-1)`, 최대 **+35%**로 반영합니다. 소환 대상과 사용 조건이 실제 게임에서 일치하는지 확인이 필요합니다.
- **광신**: 소환수에게 실제 도달하는 광신 오라 레벨을 입력합니다.
- **울버린의 심장**: 직접 투자 포인트만 입력하며 1점 +6%, 25점 이상 +30%로 처리합니다. 실제 해당 소환수에게 효과가 도달하는 경우에만 입력하세요.
- **소환수 장비 IAS / WSM**: 직접 무기를 장비하거나 장비 옵션을 갖는 소환수·강철 골렘·일부 속박 몬스터를 위해 수동 입력 가능합니다. 장비 IAS에는 점감식을 적용합니다.
- **AI 행동 대기 프레임**: 원본 참조값 또는 사용자 AI 지연 단축 모드 설정 1/3/5 등을 입력할 수 있습니다. **이 값은 공격 애니메이션 FPA와 별개**이므로 공격 모션 길이에 더해서 실제 초당 명중 횟수를 계산하지 않습니다.

### 상한 해제 관련 중요한 한계

공개 프레임표로 확인되는 EIAS 구간은 원본 D2R/LoD 몬스터 모션 자료를 참고했습니다. **마지막으로 확인된 프레임 구간을 넘는 값은 모두 이론적인 외삽**이며, 실제 D2RLoader 600 패치 및 훨윈드 패치가 소환수의 각 특수 공격과 타격 검사에 동일하게 적용되는지 별도로 측정해야 합니다.

부활 몬스터와 속박 악마, 워록 소환수처럼 **몬스터 종류·공격 스킬별 고유 모션이 필요한 경우**에는 EIAS 0 기준으로 실제 측정한 공격 프레임을 수동 입력합니다. 입력하지 않았을 때 `—`를 표시하는 것은 의도된 안전장치입니다. 오염된 자 같은 **시전자 몬스터의 주문 발사 속도**는 IAS와 다른 애니메이션을 사용할 수 있으므로 표시되는 이론값을 실제 주문 속도라고 주장하지 않습니다.

공개 프레임표 참고: [The Amazon Basin — Minion Attack Speed](https://www.theamazonbasin.com/wiki/index.php/Attack_speed) 및 각 소환수 페이지.

GitHub Pages에 업데이트할 때 `index.html`, `main.js`, **새 파일 `summons.js`**, `style.css`, `README.md`를 기존 `index.html`과 **같은 저장소 최상위**에 업로드해야 합니다. `summons.js`가 빠지면 모듈 로딩 오류로 페이지가 열리지 않습니다.

실행 테스트: `node test_summons_v16.mjs`, 이전 v1.1–v1.5 회귀 테스트.



## v1.7 — 염소인간·오염된 자 자동 프레임 계산

기존 소환 스킬 선택 UI에 통합했습니다. 염소인간 A1은 FPD 20, 오염된 자 A2 화염구는 FPD 10으로 계산합니다.
`speed = floor(256 × (100 + EIAS) / 100)`, `FPA = max(1, ceil(FPD × 256 / speed) - 1)`.
1F 필요 EIAS는 각각 +900 / +400입니다. 속도 상한 600(EIAS +500)에서는 각각 최저 3F / 1F입니다.
두 소환수의 장비 IAS·WSM 입력은 숨기고 계산에서 제외하며, 표와 CSV는 추가 필요 EIAS를 표시합니다. 기존 스킬·오라 보너스와 공유 설정 기능을 사용합니다. 포식은 활성 상태의 레벨을 입력하고 미사용 시 0을 입력합니다.
AI 대기 원본 참고값은 염소인간 5F / 오염된 자 15F이며 모션에 단순 합산하지 않습니다. 광분·가르기 시퀀스 및 실제 발사·타격 주기는 게임 내 미검증입니다.
자료: D2R_Uncapped_IAS_WarlockSummons_v1.7_Addon.zip의 이론 모델. 이전 v1.6 설명 중 두 소환수의 수동 FPA 필수 항목은 이 변경으로 대체됩니다.
검증: `node test_summons_v17.mjs` 및 `node test_core.mjs`.

## v1.7.1 — 소환수 울분 입력

모든 소환수의 오라·효과 설정에 인장: 울분 레벨을 추가했습니다. 기존 캐릭터 계산식과 동일하게 0레벨은 +0, 1레벨 이상은 레벨+4 EIAS로 반영합니다. 소환수에게 실제 적용 중일 때만 입력하세요. 기본값 0이며 캐릭터의 울분 값을 자동 상속하지 않습니다. 소환수 총 EIAS·세부 내역·프레임표·CSV·공유 설정에 반영됩니다.

## v1.7.2 — 이중 언어 무기명 및 소환수 입력별 보너스

맨손 포함 292개 선택 항목을 한글 / English 형식으로 통일했습니다. 기존 한글 이름은 유지하고 누락된 이름은 아이템 코드별 한국어 문자열을 보완했습니다. ID, 코드, WSM, 분류는 변경하지 않았습니다. 이름 보완 자료: https://github.com/SeonEngineer/D2R/blob/main/item-names.json (필터 색상/별표 제거).
소환 레벨, 악마 숙련, 포식, 광신, 울버린의 심장, 울분의 각 입력 아래 기존 붉은색 SKILL IAS 표시를 추가했습니다. 입력 레벨이 0이면 숨기고, 레벨만으로 직접 공속이 늘지 않는 소환수는 +0%와 설명을 표시합니다.

## v1.7.3 — 탈태 공속 효과

캐릭터 스킬 공속 영역에 탈태 체크박스를 추가했습니다. 활성화하면 SIAS +25를 합산하고 하단에 붉은 안내를 표시합니다. 소환수에서는 숨기며 소환수 계산에 영향을 주지 않습니다. 설정 저장·공유·초기화 및 장비 IAS 요구치에도 반영됩니다.
