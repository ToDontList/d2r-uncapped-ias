# D2R Reimagined — 공속 제한 해제 계산기 (v1.2 실험판)

**GitHub Pages에서 동작하는 독립형 정적 웹사이트.** 별도 계정 로그인, 서버, 데이터베이스, 유료 도메인, npm 빌드 과정이 필요하지 않습니다.

## 시작하기

1. 이 ZIP을 압축 해제합니다.
2. GitHub에서 **Public** 저장소를 하나 만듭니다. 예: `d2r-uncapped-ias`.
3. 압축 해제한 파일 `index.html`, `style.css`, `data.js`, `core.js`, `main.js`, `.nojekyll` 등을 **저장소 최상위(root)**에 업로드합니다. ZIP 자체를 업로드하는 것이 아닙니다.
4. GitHub 저장소 **Settings → Pages → Build and deployment → Deploy from a branch**를 선택합니다.
5. `main` 브랜치와 `/ (root)` 폴더를 지정하고 저장하면 `https://사용자이름.github.io/d2r-uncapped-ias/` 같은 주소가 발급됩니다. GitHub 설정이나 운영 정책에 따라 주소가 다를 수 있습니다.
6. 모바일에서도 같은 주소로 접근할 수 있습니다.

> 인터넷에 게시하기 전 자신의 PC에서 검사하려면 이 폴더에서 `python -m http.server 8000` 실행 → 브라우저에서 `http://localhost:8000`에 접속합니다. ES 모듈을 사용하므로 `index.html`을 `file://`로 직접 열면 일부 브라우저에서 동작하지 않을 수 있습니다.

- **1프레임까지의 이론적 프레임 구간 전체 표**, 현재 위치 표시, 프레임별 필요 추가 장비 IAS
- 설정 링크 복사 / CSV 파일 저장 / 설정 브라우저 자동 보관
- 휴대전화·PC 반응형 UI 및 고대비 표시

## 중요 — 계산 신뢰도

**이 버전은 공개하기 전에 테스트할 수 있는 기능 구현판입니다. 모든 특수 스킬에 대해 정확한 게임 판정 프레임을 보장하지 않습니다.**

| 결과 유형 | 구현 방식 | 주의 사항 |
|---|---|---|
| 기본 공격·투척·일반 모션 | 직업별 기본 공격 애니메이션 FPD와 IAS 공식 | 모딩으로 애니메이션이 바뀌면 실제값과 차이 가능 |
| 광분 | 기존 대화에 보존된 12.5~1F **이론** 브레이크포인트, 양손의 IAS 따로 반영 | 실제 쌍수 시퀀스 첫/둘째 공격의 타격 간격과 단순 1:1 대응하지 않을 수 있음 |
| 훨윈드 | 별도 타격 간격 추정식 | 게임 빌드 및 사용자 패치에 따라 실제 히트체크 다를 수 있음 |
| 열의·속사·난격·분노·암살자 복합 스킬 | 롤백/시퀀스 계수 근사 | 실제 프레임표로 사용하기 전에 검증 필요 |
| 악마술사 가르기·거울 칼날 등 | **계산 미지원**으로 명시 | 해당 스킬의 검증된 하드코딩 시퀀스 정보 필요 |
| 변신(늑대/곰) | 근사치 | 별도의 애니메이션 전용 데이터 필요 |
| 1~2F 구간 | 상한 해제 후 이론 계산 | 엔진 최소 타격 간격/내부 판정 루틴 제한은 별도 |

**원본 Reimagined 웹사이트를 코드 단위로 복제한 제품이 아닙니다.** UI와 계산기는 별도로 작성했으며, 참고 사이트의 모든 특수 공격을 정확히 재현했다고 주장하지 않습니다. 일부 지원 스킬을 순차적으로 정밀화해야 합니다.

### 기술적 전제

- 장비 IAS 점감 공식: `EIAS_item = floor(120 * IAS_total / (120 + IAS_total))`.
- 최종 EIAS: `EIAS_item + SIAS - WSM`.
- 일반 공격은 모션별 기본 프레임 데이터에 근거하여 계산합니다.
- 광분의 별도 프레임표는 사용자가 이전 대화에서 보존한 이론값을 사용합니다. 프레임당 실제 타격 여부는 검증 대상입니다.
- 듀얼 무기 WSM 평균 및 손별 무기 IAS 처리는 **표시와 모의 계산용 단순화 모델**로서 실제 광분의 시퀀스·명중 판정에 따른 차이를 포함하지 못합니다.
- 고급 `기본 모션 프레임 덮어쓰기` 항목은 Reimagined에서 모션을 수정한 경우에만 사용하세요.
- 워록 `Sigil Lethargy`는 Reimagined `skills.txt`에 명시된 attackrate -25를 반영했습니다. `Hex Purge`의 사용자 공격속도 보너스는 `passivecalc1=min(30,ln56)` (Param5=10, Param6=1)의 양수값을 적용합니다: 레벨 1 +10%, 레벨 20 +29%, 레벨 21부터 +30%. 실제 대상별 적용 조건은 게임 내 확인이 필요합니다.
- `Wolverine Aura`는 Reimagined의 `aurastatcalc3 = min(par9+blvl-1,30)`, `par9=6`을 근거로 계산하며 아이템 스킬레벨은 포함하지 않습니다.

## v1.1 변경사항

- 스킬 명칭 수정: Hex: Purge → **주술: 처단**, Sigil: Rancor → **인장: 울분**, Sigil: Lethargy → **인장: 무기력**.
- **광분**은 입력한 스킬 레벨을 바탕으로 **최대 중첩 시의 공속 보너스**를 자동 계산합니다. 중첩 수를 입력할 필요가 없습니다. 실제 전투에서 아직 중첩되지 않은 상태는 별도로 시뮬레이션하지 않습니다.
- 버프/디버프 입력창 바로 아래에 `+42% SKILL IAS` / `-25% SKILL IAS`와 같이 계산된 효과를 표시합니다. 0 입력 시 표시하지 않습니다.
- **울버린의 심장** 하단의 `1포인트 +6, 25포인트 +30(최대)` 고정 설명을 삭제하고, 입력된 직접 투자 포인트의 공속 보너스만 표시합니다.
- 늑대인간/후려치기는 해당 변신 형태가 아닌 상태에서도 잠재 공속을 `변신 시 적용`으로 구분해 표시합니다. 실제 합산에는 변신 상태일 때만 적용됩니다.

### GitHub Pages 업데이트

**중요:** 변경된 계산기를 GitHub Pages에 반영하려면 기존 `index.html`이 위치한 **같은 폴더**에 새 버전의 파일을 업로드하여 교체해야 합니다. GitHub Pages 배포 설정이 `/ (root)`이고 이전에 사이트 파일을 저장소 최상위로 옮겼다면 반드시 **최상위**를 업데이트하세요. v1.0 하위 폴더만 업데이트하면 루트 홈페이지는 바뀌지 않습니다. 이번 배포에서는 `index.html`, `core.js`, `main.js`, `style.css`, `README.md`가 변경되었고, 나머지도 ZIP으로 함께 제공합니다.
